# A. 入門

## 1. 平台是什麼

**Foxlink GPT to Cortex** = 正崴內部專屬 AI 智慧助理平台

- 整合 4 大 LLM:**Google Gemini** / **Azure OpenAI(GPT-5.4)** / **Oracle OCI** / **Cohere**
- 公司內部網路傳輸,對話紀錄存公司伺服器,**符合資安稽核**
- 支援繁中 / 英文 / 越南文,單一 Session 完整記憶
- 可上傳 PDF / Word / Excel / 圖片 / 音訊 / 程式碼 100+ 格式
- 可生成 PDF / Word / Excel / PPT / TXT 給你下載
- 進階:**深度研究** / **AI 戰情室**(查 ERP) / **自動排程**

> Speaker notes:強調「企業內網」與「資料不外流」,因為很多同仁怕問了會被外洩。

---

## 2. 登入方式 ① — Foxlink SSO(主推)

**網址:`https://flgpt.foxlink.com.tw`** ⭐(2026-05-11 起,內外網皆同)

```
舊書籤 https://flgpt.foxlink.com.tw:8443 仍可用,不需立即更換
```

**操作:**
1. 點藍色「**Foxlink SSO 登入**」按鈕
2. 系統導向公司 AD 驗證(內網已登入 AD 可能直接通過)
3. 完成回主畫面

> ⚠ **SSO 僅限有 AD 帳號的正崴員工**;外部合作夥伴/特殊帳號要走帳密
> ⚠ 外網 SSO 後仍會走 Webex/Email 雙通道驗證,**沒有 MFA bypass 風險**
> ⚠ AD 密碼改密請走公司 AD,不是 Cortex 的「修改密碼」

---

## 3. 登入方式 ② — 帳密 / 快速登入

**本地帳號**(由 IT 開立)
- 帳號密碼登入 → 忘記密碼可寄重設信(24 小時有效)

**快速登入**(Passkey / WebAuthn)⭐ — 強推
- 首次登入後可綁定 **Face ID / Touch ID / 指紋 / Windows Hello**
- 之後**不用打密碼**,生物辨識直接登入
- 資料只在裝置驗證,DB 只存公鑰,即使外洩也無法重建指紋

**手機 PWA**
- iPhone Safari → 分享 → **加入主畫面** → 變 native app
- Android Chrome → 自動跳「安裝應用程式」

> Speaker notes:現場示範 passkey 流程,並讓觀眾自己綁;PWA 強推給外勤同仁。

## 5. 語言切換(zh-TW / en / vi)

- 右上角設定 → 語言 → 選 **繁中 / English / Tiếng Việt**

# B. 對話核心

## 6. 開始第一場對話

1. 左側「**+ 新對話**」開啟
2. 輸入問題,按 **Enter / Ctrl+Enter** 送出
3. AI 串流回覆,**生成中可按 [■] 停止**
4. 對話會自動命名 + 存歷史
5. 同一對話有完整上下文記憶(整個 session)

**小技巧 ⭐**
- 問題盡量**具體**:「幫我把以下 SOP 翻譯成英文,術語維持原文」 > 「翻譯」
- 多輪追問比一次塞滿好
- 不滿意可按「**重新生成**」換答案

> Speaker notes:現場示範 — 把一份 SOP 上傳 + 問 3 個追問,看出多輪價值。

## 7. 模型怎麼挑

| 模型 | 強項 | 何時用 |
|---|---|---|
| **Gemini Pro** | 深度推理、長文件 | 報告、複雜分析、跨多檔比對 |
| **Gemini Flash** | 速度、低成本 | 翻譯、摘要、單純問答、音訊轉錄 |
| **Gemini Image** | **唯一能生圖** | 文字生圖、上傳圖修圖、風格轉換 |
| **AOAI GPT-5.4** | 長脈絡、OpenAI 相容 | 程式碼、邏輯密集任務 |
| OCI / Cohere | 補充選項 | 視管理員開放 |

> ⚠ 想生圖**一定要切 Gemini Image**,其它模型不會生圖
> 模型選擇會記到瀏覽器,切模型**不會清掉當前對話歷史**

## 8. 推理力度(Low / Medium / High)

**支援模型**:AOAI GPT-5.x / o 系列、Gemini 3.x

| 力度 | 適用 | 等待時間 | Token |
|---|---|---|---|
| Low | 一般 QA、簡單摘要 | 最快 | 最少 |
| Medium ⭐ | 預設,平衡 | 中等 | 中等 |
| High | 數學、複雜推理、code review | 較慢 | 多 2-5 倍 |

> Speaker notes:跟 token 預算掛勾,High 雖好但別亂用,平常 Medium 夠了。

---

## 9. 上傳檔案 — 支援格式

| 類型 | 格式 | 用途 |
|---|---|---|
| **文件** | PDF / DOCX / XLSX / PPTX / TXT / CSV / MD | AI 直接讀 |
| **圖片** | JPG / PNG / GIF / WEBP / HEIC / AVIF / SVG | 圖像辨識、OCR |
| **音訊** | MP3 / WAV / M4A / OGG / MP4 / AAC / WEBM | 自動轉文字後分析 |
| **程式碼** | PY / JS / TS / JAVA / C++ / GO / RUST / SQL ... 100+ | code review / 重構 |
| **設定檔** | YML / TOML / JSON / DOCKERFILE / .ENV | 解讀 / 改寫 |
| **Notebook** | IPYNB | 讀 code,跳過大 output |

> ⚠ `.env` 上傳會跳**機敏資訊確認框** — 確認沒 API key 再送

---

## 10. 上傳檔案 — 大小限制 & 禁止項

**大小上限**(管理員可調)

| 類型 | 預設上限 |
|---|---|
| 文件 / 圖片 | **10 MB** |
| 音訊 | **50 MB**(>50MB 走背景轉錄 job) |
| 程式碼 / 設定 / Log / Notebook | **5 MB hard limit** |
| 單一訊息 | 最多 **10 個檔案** |

**禁止上傳** ❌
- 影片(.mp4/.avi/.mov)
- 執行檔(.exe/.dll/.so/.apk/.ipa)
- 私鑰憑證(.pem/.key/.pfx/.jks)
- 壓縮檔(.zip/.rar/.7z)→ **先解壓再傳**

> ⚠ >500KB 的程式碼會跳「將增加 token 用量」提醒,不擋但建議裁切

---

## 11. 上傳檔案 — 3 種方式

1. **點迴紋針 📎** — 輸入框右側,可多選
2. **拖曳檔案** — 拖到頁面任何地方,出現藍框放開即可
3. **Ctrl + V 貼上圖片** ⭐ — 截圖直接貼,最快

> Speaker notes:現場示範 — 截圖 + Ctrl+V → AI 解讀截圖內錯誤訊息。
> 這招要強推,因為打字描述錯誤訊息 vs 直接貼圖,後者 10 倍快。

---

## 12. 語音輸入 ① — 點麥克風 🎤

**出現位置**
- AI 對話輸入框
- 問題反饋的描述/留言區
- 快速開單浮動按鈕等所有主要輸入點

**操作**
1. 點 🎤 → 首次跳出權限請求,選**允許**
2. 紅色閃爍 = 錄音中,旁邊顯示音量條 + 剩餘秒數
3. 停止 3 種:再點一次 / 按 Esc / 等倒數歸零
4. 辨識結果**插入游標位置**(不覆蓋既有文字)

> ⚠ 同頁有多個 🎤,只能同時錄一個

---

## 13. 語音輸入 ② — `Alt + M` 全域熱鍵 ⭐

**最快的方式** — 任何頁面、任何輸入框都能用

```
1. 滑鼠點進 textarea / input(讓游標進去)
2. 按 Alt + M
3. 右下角浮出小錄音 UI(紅色 mic + 音量條 + 倒數秒數)
4. 講話 → 停下 → 文字插入游標位置
```

**單次最長 180 秒**(比按鈕版的長)

**為誰設計**:
- 客服回覆工單(留言要打很多字)
- 教材開發者寫答案解析
- 學員筆記、滿意度意見
- 一個熱鍵走遍全站,不用記每個地方有沒有 mic 按鈕

> Speaker notes:強推這個!示範在問題反饋頁面用 Alt+M 講一段問題描述。

---

## 14. 對話歷史

**功能**
- 左側 Sidebar 自動列出所有歷史對話(自動命名)
- **搜尋框** — 關鍵字找舊對話
- **重新命名** / **Pin 釘選** / **刪除**(滑鼠 hover 出現)
- **資料夾分類**(2026 新增)— 拖曳整理
- 歷史永久保留在公司伺服器,可隨時回去問

**Token 用量**
- 每場對話右上角可看當下消耗
- 超長對話建議**開新對話**(不然每輪都重發歷史 → 燒 token)

## 15. 分享對話

**情境**:同事在問同樣的問題,你想把答案直接給他

1. 對話右上角「**分享**」→ 產生唯讀連結
2. 連結**僅限正崴內部登入者可看**(SSO 後才能開)
3. 對方點開可看到完整對話 + 附件,**但不能繼續對話**
4. 也可選**「分享到 Webex」**(透過 Bot 推給 room/個人)

> Speaker notes:這對 IT、HR 公告很好用 — 一次答完所有人。

## 16. AI 自動生檔(下載 PDF/Excel/Word/PPT)

**用法**:在問題裡告訴 AI 用三個反引號包這個語法

````markdown
請幫我把這份庫存資料整理成 Excel:

```generate_xlsx:庫存_2026-05.xlsx
（這裡是表格內容,AI 自己填）
```
````

**支援格式**

| 語法 | 產出 |
|---|---|
| `generate_xlsx:名稱.xlsx` | Excel(支援多工作表) |
| `generate_docx:名稱.docx` | Word |
| `generate_pdf:名稱.pdf` | PDF(中文需 NotoSansTC 字型) |
| `generate_pptx:名稱.pptx` | PowerPoint |
| `generate_txt:名稱.txt` | 純文字 |

回覆下方出現**藍色下載按鈕**

## 17. 頂端工具列 — 5 個開關

對話頁頂端工具列,**勾了才會生效**,不勾就走純對話:

| 開關 | 圖示 | 啟用後 AI 會 |
|---|---|---|
| **技能 Skill** | ✦ 紫 | 套用對應 system prompt / 角色 |
| **知識庫 KB** | 🗄️ 藍 | 從掛載 KB 檢索相關段落 |
| **API 連接器** | ⚡ 琥珀 | 呼叫 DIFY / REST / ERP Procedure |
| **MCP 工具** | 🌐 青 | 呼叫 MCP 伺服器(搜尋、執行 code) |
| **AI 戰情室** | 📊 橘 | 快速跳到指定查詢任務 |

> ⚠ 狀態只影響**之後**的訊息,不會回溯
> ⚠ 純文字對話**全部不勾**可降低延遲與 token

---

## 18. 技能 Skill 市集

**是什麼**:把常用 prompt / 角色 / 工作流程**包裝成可掛載的「技能」**

**典型例子**
- 「**翻譯小助手**」— 自動翻成指定語言、術語維持原文
- 「**SOP 改寫器**」— 把粗稿改成正式 SOP 格式
- 「**會議紀錄生成**」— 上音訊 → 自動生紀錄 + action items
- 「**程式 code review**」— 自動掃常見 anti-pattern

**操作**
1. Sidebar → **技能市集** → 找到要用的
2. 點「掛載」 → 對話頂端工具列的「技能」勾起來
3. 之後每則訊息 AI 都會帶這個技能

> ⭐ 任何人都可以「申請開發」自己用的技能,給 IT 開單即可

---

## 19. 自建知識庫(KB)市集

**是什麼**:把**自己 / 部門的文件**上傳建索引,讓 AI 回答時可以查

**典型例子**
- 部門 SOP 庫(50 份 PDF)→ AI 回答時自動翻 SOP
- 個人專案文件夾 → 跨檔案問問題
- 公司公告/規章 → HR 問答機器人

**操作**
1. Sidebar → **知識庫市集** → 建一個新 KB
2. 上傳 PDF / Word / Excel / PPTX(可拖多檔)
3. 系統自動切段 + 向量化(等幾分鐘)
4. 對話頂端「知識庫」勾起來 → AI 自動檢索

**分享**:可設「僅自己 / 指定使用者 / 部門 / 廠區」共享

> ⚠ KB 名稱寫清楚,因為 AI 會用名稱判斷該不該查

---

## 20. API 連接器 + MCP 工具

**API 連接器**(DIFY / REST / **ERP Procedure**)
- 把外部系統的 API 包成工具給 AI 呼叫
- **ERP Procedure** ⭐:可以直接讓 AI 跑 ERP function/procedure
  - 例:「幫我查工號 12345 的本月加班時數」
- 每個工具有「**?**」按鈕看參數說明
- 🔒 圖示代表參數已被管理員鎖定

**MCP 工具**
- 即時外部查詢(網路搜尋、Oracle 程式搜尋、code 執行)
- 由 IT 預先設定,你只需要勾選

> Speaker notes:強調 ERP Procedure 是新功能,以前要找 IT 跑的 query 現在 AI 自己跑

---

## 21. 文件範本(Doc Template)

**情境**:每週週報、簽呈、公文都要套同一個格式

**做法**
1. **更多功能 ▼ → 文件範本**
2. 選範本(IT 預先建的 / 自己建的)
3. 填欄位 → 一鍵生成 Word / PDF

**和 Skill 差別**
- Skill = 改寫 / 自由創作
- Template = 固定格式、欄位化、適合行政流程

> Speaker notes:HR、總務、品管常用,先問現場誰有重複文件痛點。

---

## 22. 工具列個人化(拖曳、隱藏)

**情境**:技能/KB 開太多,清單一拉到底

**操作**(在任一面板內)
- 滑鼠按住每列左邊的 **≡ 握把** → 上下拖排序
- hover 出現 **👁️ 眼睛圖示** → 點一下隱藏
- 面板底部「**▾ 已隱藏 (N)**」 → 點開可恢復
- 頂部搜尋框找特定項目

> ⚠ 隱藏**僅存本機 localStorage**,換瀏覽器要重設

---

## 23. 「我該用哪個工具?」決策圖

```
要問什麼?
├─ 純對話 / 翻譯 / 文案     → 不勾任何工具
├─ 要 AI 用某個角色說話      → 勾「技能」
├─ 要查公司內部文件          → 勾「知識庫」
├─ 要查 ERP / 跑 procedure   → 勾「API 連接器」
├─ 要查最新網路資料          → 勾「MCP 工具」(含 web search)
└─ 要查 ERP 並出圖表 / 儀表板 → 進「AI 戰情室」
```

> 💡 **不確定就全勾** — AI 會自己判斷該用哪個(會稍慢但不會出錯)

## 24. 深度研究 — 何時用

**Use case**:複雜題目,單次對話搞不定的

- 競品分析、技術評估
- 市場調查、法規解析
- 新供應商 due diligence
- 內部新議題 onboarding

**特色**
- AI **自動拆 2 / 5 / 8 / 12 個子問題**分別調查
- 每個子問題可結合 **KB / 技能 / MCP / 上傳檔案**
- **背景非同步執行** — 跑 10–30 分鐘可關掉視窗繼續工作
- 完成自動生 Word / PDF / PPT / Excel 下載

> ⚠ Token 消耗高,用 Gemini Pro,**建議標準(5 個)起跳**

---

## 25. 深度研究 — 3 步驟

```
Step 1: 設定問題
   ├─ 主題 + 深度(2/5/8/12)
   ├─ 全局附件(共用 PDF / 圖)
   ├─ 整體資料來源(KB / API / MCP)
   ├─ 自動建議 KB(輸入後 1 秒系統自動選)
   └─ 引用前次研究(最多 3 筆,做延續性研究)

Step 2: 確認子問題清單
   ├─ AI 拆好的子問題可編輯 / 排序 / 增刪
   └─ 每個子問題可獨立設方向、附件、網搜開關

Step 3: 即時預覽(背景跑)
   ├─ 每個子問題完成就秀摘要
   ├─ 全部完成 → 自動整合報告 + 生成下載檔
   └─ ↺ 編輯重跑:單獨重跑不滿意的子問題,其它保留 ⭐
```

> ⭐ 「編輯重跑」是省 token 神器 — 不用整個任務重來
